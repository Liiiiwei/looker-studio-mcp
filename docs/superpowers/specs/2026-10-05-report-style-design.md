# Looker Studio 報表樣式規格

日期：2026-10-05

## 目的

讓每份客戶成效報表長得一致、五秒內讀得到結論。規格做進範本，新客戶報表由範本複製而來，不逐份調整。

規格鎖的是結構與角色（版面、層級、哪個位置用哪種顏色角色）。色碼與字體是範例值，換客戶品牌時只改「顏色角色」表的數值，其餘不動。

## 一、內容規則

1. 每頁的頁標題寫成「頁名｜這一頁回答的問題」，一頁一個問題。回答不了這個問題的圖表移到別頁。
2. 由上到下固定三段：關鍵數字 → 趨勢 → 明細。
3. 每個關鍵數字都帶比較：上期比較、目標達成率、預算進度，三選一。上期比較用「上一個時段」；上一個時段沒有資料時會顯示「無資料」，保留不隱藏。
4. 一頁的關鍵數字 4 或 6 個，不超過 6 個。
5. 關鍵數字由左到右照漏斗順序排：花費 → 曝光 → 點擊 → 加車數 → 購買數 → 購買金額。
6. 圖表類型依問題決定：

| 要回答的問題 | 圖表 |
|---|---|
| 隨時間怎麼變 | 折線圖 |
| 誰大誰小 | 橫條圖，由大到小排序 |
| 各佔多少 | 堆疊條；類別不超過 5 個 |
| 實際對目標 | 子彈圖或進度條 |
| 要查單筆 | 表格 |

不使用圓餅圖、儀表圖、立體圖。

## 二、版面規則

Looker Studio 有兩種頁面版面，網格的落實方式不同：

- **回應式版面**（新增頁面的預設）：頁面由上到下分成區段，元件在區段內由左到右排列。寬度隨螢幕縮放，不能輸入像素，高度只能用拖曳調整。
- **任意形式版面**：畫布寬 1200px，元件的位置與大小可以輸入數值。

### 網格

兩種版面都把一列分成 12 欄，元件只能佔下列幾種欄數：

| 佔欄數 | 任意形式版面的寬度 | 用途 |
|---|---|---|
| 2 | 176px | 評量表（一列 6 個） |
| 3 | 272px | 評量表（一列 4 個） |
| 4 | 368px | 小圖（一列 3 個） |
| 6 | 560px | 半版圖表 |
| 12 | 1136px | 全版圖表、表格 |

任意形式版面的左右邊界 32px、欄寬 80px、欄距 16px。

回應式版面的同一列元件，用區段樣式的「排列方式」設成垂直靠上，高度拖到相同。

### 間距

| 位置 | 數值 |
|---|---|
| 同一列元件之間 | 16px |
| 區段之間 | 32px |
| 元件內距 | 16px |

### 頁面骨架

每頁由上到下依序是：

| 區段 | 高度 | 內容 |
|---|---|---|
| 頁首 | 72px | 左：頁標題。右：日期範圍控制項 |
| 關鍵數字列 | 112px | 評量表 4 或 6 個，同高同樣式 |
| 主圖 | 280px | 一張全版，或兩張半版 |
| 明細 | 依列數 | 表格，預設依主要指標由大到小排序 |

頁首與關鍵數字列的位置每頁相同。

### 對齊

- 數字靠右，文字靠左
- 表格的維度欄在最左，主要指標緊接其後
- 同一列的元件頂端對齊、高度相同

## 三、樣式規格

### 顏色角色

| 角色 | 用在哪裡 | 範例值 |
|---|---|---|
| 主色 | 頁首底色、表頭底色、圖表第一數列 | `#1565C0` |
| 強調色 | 這一頁最重要的那一個數字或那一條線；一頁不超過 3 處 | `#F57C00` |
| 主色上的文字 | 頁首標題、表頭文字 | `#FFFFFF` |
| 主要文字 | 數字、表格內容 | `#212121` |
| 次要文字 | 標籤、座標軸、註記 | `#616161` |
| 線條 | 外框、格線 | `#E0E0E0` |
| 斑馬紋 | 表格偶數列底色 | `#F5F5F5` |
| 頁面底色 | 畫布 | `#FFFFFF` |
| 正向 | 比較值變好 | `#2E7D32` |
| 負向 | 比較值變差 | `#C62828` |

- 正向與負向只用在比較值，不用在數列顏色
- 跨平台比較的圖表裡，Meta 固定用主色，Google Ads 固定用強調色，整份報表不變；這類圖表所在的頁面不再另外使用強調色
- 花費、每次成果成本這類「越低越好」的指標，比較值的正負向顏色要反過來設

### 字級

字體：Arial（範例值），整份報表只用一種。

| 層級 | 大小 | 粗細 | 顏色角色 |
|---|---|---|---|
| 頁標題 | 24px | 一般 | 主色上的文字 |
| 區段標題、圖表標題 | 16px | 一般 | 主要文字 |
| 評量表數字 | 28px | 一般 | 主要文字或強調色 |
| 評量表標籤、比較值 | 隨數字字級自動縮放 | 一般 | 次要文字 |
| 表頭 | 12px | 粗體 | 主色上的文字 |
| 表格內容、座標軸、圖例 | 12px | 一般 | 主要文字 |

不使用小於 12px 的字。評量表只有一個「字型大小」設定，設 28px 後標籤與比較值會自動落在 12px 左右；留在「自動」會隨內容縮到看不清楚。

### 數字格式

| 類型 | 格式 | 範例 |
|---|---|---|
| 金額 | 千分位、無小數 | $51,260 |
| 次數 | 千分位、無小數 | 406,918 |
| 比率 | 一位小數 | 3.2% |
| 廣告投資報酬率 | 兩位小數 | 1.62 |
| 比較值 | 帶正負號的百分比、一位小數 | +12.4% |

欄位的「顯示格式」一律留在「預設」；設成 None 會失去千分位。金額的小數位數在評量表樣式的「小數點精確度」設 0。

### 欄位命名

報表上顯示的欄位名稱全部用中文，同一個指標在整份報表只有一個名稱。

| 資料來源欄位 | 顯示名稱 |
|---|---|
| Impressions | 曝光 |
| Clicks／點擊 | 點擊 |
| Total Cost／花費 | 花費 |
| 加車數 | 加車數 |
| 購買數 | 購買數 |
| 購買轉換值 | 購買金額 |
| Date | 日期 |
| 行銷活動 | 行銷活動 |

### 元件樣式

| 元件 | 規則 |
|---|---|
| 評量表 | 白底、1px 線條色外框、圓角 4px、內距 16px、行高 32px、字型大小 28px；標籤在上、數字在下、比較值在數字下方 |
| 折線圖 | 線寬 2px、不顯示資料點、水平格線用線條色、不顯示垂直格線、圖例在上方靠左 |
| 橫條圖 | 單一顏色、顯示資料標籤、不顯示格線 |
| 表格 | 表頭主色底、內容斑馬紋、不顯示直線、顯示列號、每頁 10 列 |
| 日期控制項 | 白底、主要文字色、1px 線條色外框；放在主色底的頁首上也維持白底，不用透明底 |

外框、陰影、底色三種裝飾裡，整份報表只用外框。

## 四、落到 Looker Studio

1. 在「主題和版面配置」把主色、強調色、文字色、字體設成上表的值，之後新增的圖表自動套用。
2. 個別元件要換顏色時，從色盤的「主題」那一列挑，不逐一輸入色碼；色盤上方的現成色塊只是近似色。
3. 在範本最後加一頁「元件樣板」，放好符合規格的評量表、折線圖、橫條圖、表格、日期控制項各一個。新增元件時複製樣板再換欄位，不從空白插入；從空白插入的評量表樣式會和既有的不一致。
4. 欄位顯示名稱在圖表的欄位設定裡改（點欄位左側的圖示，填「顯示名稱」）。資料來源可能被其他報表共用，不在資料來源層級改。
5. 範本的每一頁依「頁面骨架」重排。

## 五、驗收

每份範本逐頁檢查，全部符合才算通過：

1. 頁標題有寫這一頁回答的問題
2. 關鍵數字是 4 或 6 個，照漏斗順序排，每個都開了比較（上一個時段沒有資料而顯示「無資料」算通過）
3. 同一列的評量表外框、字級完全相同；高度在任意形式版面完全相同，在回應式版面相差不超過 4px
4. 所有元件都佔 2、3、4、6、12 欄其中之一，同一列元件頂端對齊、高度相同
5. 強調色出現不超過 3 處
6. 頁面上沒有英文欄位名稱
7. 沒有小於 12px 的字
8. 主色底上的文字是白色，控制項是白底
9. 金額無小數，比率一位小數
10. 沒有圓餅圖、儀表圖、立體圖
